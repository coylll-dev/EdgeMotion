# EdgeMotion

Управление Windows жестами мыши от краёв экрана, вдохновлённое навигацией Android.
Первая версия: **0.1.0**. C# / WinForms / .NET Framework 4.8, без внешних библиотек.

## Запуск

1. В PowerShell из папки проекта выполните `./build.ps1 -Test`.
2. Откройте `artifacts/EdgeMotion.exe`.
3. Приложение впервые запускается в **режиме проверки**. Зажмите правую кнопку мыши
   в пределах 12 пикселей от края экрана, проведите и отпустите. Результат появится
   в журнале окна; если окно скрыто — в уведомлении трея.
4. Подберите чувствительность, выключите «Проверка без выполнения действий»,
   нажмите «Сохранить настройки» и сверните в трей.

Windows 10/11 с .NET Framework 4.8. Для локальной сборки достаточно встроенного
компилятора .NET Framework; устанавливать Visual Studio не требуется.
Альтернатива для разработки: `dotnet build EdgeMotion.csproj -c Release`
с .NET SDK и доступными reference assemblies .NET Framework 4.8.

## Жесты по умолчанию

| Жест с зажатой правой кнопкой | Действие Windows |
| --- | --- |
| От нижнего края вверх | Показать / вернуть рабочий стол, Win+D |
| Снизу вверх, остановиться на 450 мс, отпустить | Представление задач, Win+Tab |
| От левого или правого края к центру | Назад в активном приложении, Alt+← |
| По диагонали внутрь от нижнего угла | Голосовой ввод, Win+H |
| От верхнего края вниз | Быстрые настройки Windows 11 / центр уведомлений Windows 10, Win+A |
| Влево вдоль нижнего края | Предыдущее окно, Alt+Tab |
| Вправо вдоль нижнего края | Обход окон в обратном направлении, Alt+Shift+Tab |

Действие выполняется **после отпускания кнопки**, включая удержание для «Недавних».
В настройках можно назначить любое встроенное действие, Пуск, Поиск или отключить
отдельный жест. Alt+Tab и Alt+Shift+Tab работают с порядком окон Windows;
это не хронологическая лента приложений Android.

## Управление

- `Ctrl+Alt+G` — включить / приостановить жесты. Если сочетание занято другой
  программой, приложение сообщит об этом; используйте меню трея.
- `Esc` во время удержания правой кнопки — отменить жест.
- Закрытие окна крестиком скрывает его в трей. «Выход» завершает программу и
  снимает перехват мыши. Двойной щелчок по значку открывает настройки.
- Обычный правый клик у края восстанавливается, если перемещение не превышает
  10 пикселей. Неудачный свайп с большим перемещением отменяется без контекстного меню.
- Жест отменяется спустя 5 секунд. Полноэкранные окна пропускаются по умолчанию.
  Проверка полноэкранности основана на границах активного окна; её можно отключить.
- Зоны определяются отдельно для каждого монитора, включая координаты слева / выше
  основного. Порог задаётся в физических пикселях; для экранов с высоким DPI его
  можно увеличить. Начало жеста остаётся привязанным к исходному монитору.
- Настройки применяются сразу; кнопка сохранения записывает их для будущих запусков
  в `%LOCALAPPDATA%/EdgeMotion/settings.xml`. Журнал последних 50 действий хранится
  только в памяти. Автозапуск не устанавливается.

«Назад» поддерживается браузерами и Проводником, но не универсален для всех
приложений. Голосовой ввод требует настроенных компонентов Windows и подходящего
поля ввода. Для повышенных приложений Windows может блокировать синтетический
ввод из обычного процесса. Программа по умолчанию запускается без прав администратора.
Не удерживайте Ctrl, Alt, Shift или Win во время жеста: выполнение сочетания будет
пропущено с сообщением, чтобы не смешивать клавиши.

## Архитектура

- `GestureRecognizer` — независимый от Windows распознаватель, проверяемый тестами.
- `MouseHook` — глобальный `WH_MOUSE_LL`; захватывает только правую кнопку при старте
  у края. События движения проходят дальше. Работа UI и отправка клавиш вынесены
  из обработчика перехвата в очередь основного потока.
- `Native` — Win32 API и отправка сочетаний через `SendInput`.
- `MainForm` — настройки, режим проверки, журнал, трей и глобальная пауза.
- `Settings` — XML с атомарной заменой файла и ограничением числовых параметров.

Ссылки на документацию: [перехваты Windows](https://learn.microsoft.com/en-us/windows/win32/api/winuser/nf-winuser-setwindowshookexw),
[SendInput](https://learn.microsoft.com/en-us/windows/win32/api/winuser/nf-winuser-sendinput),
[сочетания клавиш Windows](https://support.microsoft.com/en-us/windows/keyboard-shortcuts-in-windows-dcc61a57-8ff0-cffe-9796-cb9706c75eec).

## Разработка и публикация

`./build.ps1 -Test` компилирует программу с предупреждениями как ошибками и запускает
20 проверок распознавания и сериализации. Проверки не посылают клавиши Windows.
GitHub Actions выполняет такую же сборку и сохраняет ZIP с EXE и конфигурацией
при push и pull request. Исполняемые файлы исключены из Git.

Проверка на настоящем рабочем столе: режим проверки → каждый жест → пауза горячей
клавишей → правый клик на краю → отмена Esc → второй монитор → сохранение и перезапуск.
Затем выключите режим проверки и проверьте действия в Проводнике и браузере.
Системные действия, DPI и поведение конкретных программ требуют такой ручной проверки;
успешная сборка и тесты распознавателя её не заменяют.

Следующие версии: индикатор движения у края, исключения для отдельных программ,
выбор кнопки активации и запуск вместе с Windows по желанию пользователя.
