# EdgeMotion

Управление Windows жестами мыши от краёв экрана, вдохновлённое навигацией Android.
Версия: **0.2.0**. C# / WinForms / .NET Framework 4.8, без внешних библиотек.

Настройки оформлены светлыми карточками со схемами движения, крупными переключателями
и отдельным выбором действия с пояснениями. Визуальное направление вдохновлено
[Light Glass в Realme UI 7.0](https://www.realme.com/in/realme-ui-7);
элементы рисуются средствами WinForms без размытия содержимого рабочего стола.

## Запуск готовой программы

1. Скачайте ZIP из раздела [Releases](https://github.com/coylll-dev/EdgeMotion/releases),
   когда опубликована готовая версия. До первого релиза сборки доступны в
   [GitHub Actions](https://github.com/coylll-dev/EdgeMotion/actions): откройте успешный
   запуск и скачайте артефакт `EdgeMotion-windows` (требуется вход в GitHub).
2. Распакуйте архив в любую папку и откройте `EdgeMotion.exe`.
3. Приложение впервые запускается в **режиме проверки**. Зажмите правую кнопку мыши
   в пределах 12 пикселей от края экрана, проведите и отпустите. Результат появится
   в журнале окна; если окно скрыто — в уведомлении трея.
4. Подберите чувствительность, выключите «Проверка без выполнения действий»,
   нажмите «Сохранить настройки» и сверните в трей.

Для запуска нужны Windows 10/11 и .NET Framework 4.8. Visual Studio нужна только
для разработки и сборки исходников.

## Сборка в Visual Studio

1. В Visual Studio Installer выберите рабочую нагрузку **«Разработка классических
   приложений .NET»** и компонент **.NET Framework 4.8 Targeting Pack**.
   Подробнее: [компоненты для разработки .NET Framework](https://learn.microsoft.com/en-us/dotnet/framework/install/guide-for-developers).
2. Клонируйте репозиторий или скачайте исходники и откройте `EdgeMotion.sln`
   в Visual Studio 2022 или новее.
3. Назначьте проект **EdgeMotion** запускаемым (Set as Startup Project).
4. Выберите конфигурацию **Release** и платформу **Any CPU**.
5. Выполните **Сборка → Собрать решение** (`Ctrl+Shift+B`).
6. Готовые `EdgeMotion.exe` и `EdgeMotion.exe.config` находятся в `bin/Release/`.
   Храните оба файла рядом. `F5` запускает приложение под отладчиком.

Решение содержит приложение и отдельный консольный проект `EdgeMotion.Tests`.
Он проверяет собранное приложение через ссылку на проект; NuGet-пакеты не нужны.
Для проверки назначьте `EdgeMotion.Tests` запускаемым и нажмите `Ctrl+F5`.
После проверки верните запускаемым проект `EdgeMotion`. Проверки выполняются
консольным приложением, а не через Test Explorer.

## Жесты по умолчанию

| Жест с зажатой правой кнопкой | Действие Windows |
| --- | --- |
| От нижнего края вверх | Показать / вернуть рабочий стол, Win+D |
| Снизу вверх, остановиться на 450 мс, отпустить | Представление задач, Win+Tab |
| От левого или правого края к центру | Назад в активном приложении, Alt+← |
| По диагонали внутрь от нижнего угла | Голосовой ввод, Win+H |
| От верхнего края вниз | Быстрые настройки Windows 11 / центр уведомлений Windows 10, Win+A |
| Влево вдоль нижнего края | Предыдущее окно, Alt+Tab |
| Вправо вдоль нижнего края | Обход окон в обратном направлении, Alt+Shift+Tab |

Действие выполняется **после отпускания кнопки**, включая удержание для «Недавних».
В настройках можно назначить любое встроенное действие, Пуск, Поиск или отключить
отдельный жест. Alt+Tab и Alt+Shift+Tab работают с порядком окон Windows;
это не хронологическая лента приложений Android.

## Управление

- `Ctrl+Alt+G` — включить / приостановить жесты. Если сочетание занято другой
  программой, приложение сообщит об этом; используйте меню трея.
- `Esc` во время удержания правой кнопки — отменить жест.
- «История и помощь → Восстановить ввод» или аналогичный пункт трея отпускает
  Win, Alt, Ctrl и Shift и ставит жесты на паузу. Перед нажатием отпустите все клавиши.
- Быстрые повторные жесты ограничены интервалом 300 мс: очередь действий не копится.
  Просроченные действия и жесты для уже сменившегося активного окна отбрасываются.
  Обычные правые клики не имеют этого ограничения.
- Закрытие окна крестиком скрывает его в трей. «Выход» завершает программу и
  снимает перехват мыши. Двойной щелчок по значку открывает настройки.
- Обычный правый клик у края восстанавливается, если перемещение не превышает
  10 пикселей. Неудачный свайп с большим перемещением отменяется без контекстного меню.
- Жест отменяется спустя 5 секунд. Полноэкранные окна пропускаются по умолчанию.
  Проверка полноэкранности основана на границах активного окна; её можно отключить.
- Зоны определяются отдельно для каждого монитора, включая координаты слева / выше
  основного. Порог задаётся в физических пикселях; для экранов с высоким DPI его
  можно увеличить. Начало жеста остаётся привязанным к исходному монитору.
- Настройки применяются сразу; кнопка сохранения записывает их для будущих запусков
  в `%LOCALAPPDATA%/EdgeMotion/settings.xml`. Журнал последних 50 действий хранится
  только в памяти. Автозапуск не устанавливается.

«Назад» поддерживается браузерами и Проводником, но не универсален для всех
приложений. Голосовой ввод требует настроенных компонентов Windows и подходящего
поля ввода. Для повышенных приложений Windows может блокировать синтетический
ввод из обычного процесса. Программа по умолчанию запускается без прав администратора.
Не удерживайте Ctrl, Alt, Shift или Win во время жеста: управление будет поставлено
на паузу с сообщением, чтобы не смешивать клавиши. При частичной отправке сочетания
программа отпускает только собственные нажатия; при неудаче повторяет отпускание
в фоне. Если ввод выглядит необычно, используйте восстановление ввода.

## Архитектура

- `GestureRecognizer` — независимый от Windows распознаватель, проверяемый тестами.
- `MouseHook` — глобальный `WH_MOUSE_LL`; захватывает только правую кнопку при старте
  у края. Перехваты работают на отдельном потоке с циклом сообщений; события движения
  проходят дальше. `WH_KEYBOARD_LL` отслеживает физическое состояние клавиш и Esc,
  не блокирует клавиатуру и не записывает текст или историю нажатий.
- `InputSafety` — одно действие одновременно, срок действия 250 мс и учёт клавиш,
  вставленных частично принятым пакетом. Выполнение вынесено с потока UI и перехватов.
- `Native` — Win32 API, корректные флаги расширенных клавиш, `SendInput` и фоновое
  повторное отпускание собственных клавиш после неудачи.
- `MainForm` — настройки, режим проверки, журнал, трей и глобальная пауза.
- `Settings` — XML с атомарной заменой файла и ограничением числовых параметров.

Ссылки на документацию: [перехваты Windows](https://learn.microsoft.com/en-us/windows/win32/api/winuser/nf-winuser-setwindowshookexw),
[SendInput](https://learn.microsoft.com/en-us/windows/win32/api/winuser/nf-winuser-sendinput),
[сочетания клавиш Windows](https://support.microsoft.com/en-us/windows/keyboard-shortcuts-in-windows-dcc61a57-8ff0-cffe-9796-cb9706c75eec).

## Разработка и публикация

Проекты компилируются с предупреждениями как ошибками. Консольный проект тестов
выполняет 42 проверки распознавания, сериализации и защиты ввода, не посылая клавиши
Windows. Стресс-проверка имитирует 10 000 быстрых сочетаний; проверяются также частично
принятые пакеты, ошибки отпускания и физически удерживаемые клавиши.
GitHub Actions собирает то же решение через MSBuild и запускает тесты при push
и pull request. Артефакт `EdgeMotion-windows` скачивается как ZIP с EXE и конфигурацией.
PowerShell-скрипты для сборки не используются. Исполняемые файлы исключены из Git.

### Публикация версии вручную

1. Проверьте приложение и тесты, обновите номер версии в `src/AssemblyInfo.cs`
   и соберите решение в конфигурации **Release**.
2. Закоммитьте исходники этой версии и отправьте коммит на GitHub.
3. В Проводнике выделите `EdgeMotion.exe` и `EdgeMotion.exe.config` из `bin/Release/`
   и создайте ZIP, например `EdgeMotion-0.2.0-windows.zip`.
   Тестовое приложение, папки `obj` и личные настройки в архив не включайте.
4. В разделе **Releases → Draft a new release** создайте тег, например `v0.2.0`,
   на соответствующем коммите, добавьте описание изменений и прикрепите ZIP.
5. Нажмите **Publish release**. Пользователи скачивают программу из Releases;
   исходники и история разработки остаются в репозитории.

Workflow проверяет коммиты и подготавливает артефакты, но не публикует релизы:
готовую проверенную версию автор выпускает вручную.

Проверка на настоящем рабочем столе: режим проверки → каждый жест → пауза горячей
клавишей → правый клик на краю → отмена Esc → второй монитор → сохранение и перезапуск.
Затем выключите режим проверки и проверьте действия в Проводнике и браузере.
Системные действия, DPI и поведение конкретных программ требуют такой ручной проверки;
успешная сборка и тесты распознавателя её не заменяют.

Следующие версии: индикатор движения у края, исключения для отдельных программ,
выбор кнопки активации и запуск вместе с Windows по желанию пользователя.
